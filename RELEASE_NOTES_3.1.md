# HYPERION DIGITAL EX 3.1

On a title's store page, when the release lists both a Setup installer and a portable exe (the same version), you now get two buttons: Install Desktop and Get Portable. Install Desktop runs the Setup as before. Get Portable downloads the standalone exe, checks its SHA-256, saves it to your Downloads folder, and offers to open the folder or run it. AGE OF CHICS™ BY HYPERION 2.5.1 is the first title with both builds shown this way. The H icon, Desktop shortcut and portable-on-Desktop Setup, and the AGE OF CHICS featured/library pin, are unchanged.
